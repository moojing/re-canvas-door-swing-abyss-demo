遊戲手冊１

（改變搖桿模式時，閱讀時就替換此文件中提到的按鍵。）

 「呼叫START畫面」

　　在遊戲中按下Ｙ鍵。

　　以下場合無法呼叫：事件中、受到攻擊時、舉起武器時。

　　在這個畫面下可以使用以下機能。

　　武器裝備

　　使用道具

　　閱覽文件

　　放置道具…等。

 「檢視MAP」

　　在START畫面的上方Menu中，選擇「MAP」。

　　（也可以下遊戲中按下Ｚ鍵）。

　　＊在還未拿到MAP的場合，只能表示出進去過的房間。

 「在MAP中確認可能的情報」

　　藍色的房間：現在所在的房間。

　　綠色的房間：曾經去過的房間。

　　紅色的門：被鎖上的門。

　　黃色的門：沒被鎖上的門。

　　在MAP畫面中按下Ａ鍵，呼叫出道具清單。

　　＊清單顯示時，可以使用以下機能。

　　確認放置道具的種類。

　　確認放置道具的位置。

 「推東西」

　　如果有能讓東西移動的方向，對東西持續輸入控制鍵。（或者輸入十字方向鍵）

 「落差的上升與下降」

　　在跟遊戲主角的腰差不多高度的落差前押下Ａ鍵。

　　（也有可以推也可以爬上去的落差。）

 「武器的裝備」

　　在START畫面的道具中，選擇可以裝備的武器，實行「裝備」的指令。

　　（若沒有裝備武器，就無法對敵人攻擊。）

 「關於攻擊態勢」

　　按下板機按鈕Ｒ。

　　（舉起武器會先瞄準最近的敵人。）

 「關於攻擊方法」

　　在攻擊態勢中按下Ａ鍵。

　　（使用現在裝備中的武器攻擊。）

 「關於快速轉身」

　　控制器（十字鈕）輸入「下」的狀態中按下Ｂ鍵。 

「道具的詳細調查」

　　在START的畫面選擇要調查的道具，選擇「調查」指令。

　　（會顯示道具的詳細情報。）

關於夥伴的切換（改變搖桿模式時，閱讀時就替換此文件中提到的按鍵）

「夥伴切換」

　　遊戲的系統是操作兩個特性相異的主角─Rebecca和Billy來進行。

　　可操作的角色：主要角色。

　　非操作的角色：夥伴角色。

　　以下就這樣稱呼。

「夥伴角色的操作」

　　夥伴角色會自動作出基本的行動。（可以使用Ｃ軸來操作移動。）

「單獨行動‧共同搜索」　

　　狀態畫面中選擇「PARTNER」，可以給予夥伴角色指令。　

　　‧單獨行動：夥伴離開行動。

　　‧共同搜索：夥伴自動追隨。　　

　　‧攻擊：夥伴自動攻擊。

　　‧待機：夥伴不會攻擊。

　　＊共同搜索╱單獨行動的切換，可以使用START╱PAUSE。

「主角交換」

　　狀態畫面中押下Ｘ鍵，主要角色就會交換。（遊戲中也可以）

　　按照不同狀況交換主角來通過障礙。

「交換道具」

　　當夥伴角色距離很近的時候，可以再狀態畫面中進行道具交換。

　　＊選擇主要角色的道具框，就會出現「交換」的指令。

「角色特性：Rebecca」

　　身為S.T.A.R.S.隊員的Rebecca，擁有以下的特性：

　　‧調和藥草系的道具。　

　　‧受敵人攻擊的防禦力低。

　　‧可以用調和器具採取特定的藥品。

「角色特性：Billy」

　　原為海軍陸戰隊的Billy，擁有以下的特性：

　　‧不能調和藥草系的道具。

　　‧受敵人攻擊的防禦力高。

　　‧能推動一般的重物。

「夥伴角色被攻擊？」

　　夥伴和主要角色一樣，若受到敵人危險的攻擊，最後可能會死亡。要常常注意狀態。

　　另外，夥伴在別的房間受到攻擊，會使用無線電求助，聽到無線電時，就趕快去幫忙吧。

「和夥伴一起合作」

　　在任務之中，有些無法獨自解決的東西，無法通過時，試試看和夥伴一起合作吧！

乘客的日記

7月14日

今天，上司下達了一個指示。

詳情是說有必要調查Arkley山區中的研究所遺址，而我們則被指派負責調查。

移動分成兩梯，先出發的隊伍似乎已經開始調查遺棄實驗體或廢棄物了。

7月16日

可惜的是，為了這個調查，試作B.O.W.「Type-y 139」的研究也被迫暫時中斷。

「Type-y 139」也是……甲殼類對T病毒的反應也存有許多未知，就一個研究對象而言，令我大感興趣。

就算只注入少量的「T」，甲殼類也會因種類或生長環境的不同，而產生讓外殼變硬、巨大化、體內毒素異常增值、智能發達等反應。若是

能好好控制的話，應該能具備作為兵器所需的變態要素吧。

但是，甲殼過度的發達，卻同時也引發了強度變低的問題，尤其是特定部位，更弱化到令人意外的程度。

而那個部位偏偏又是頭部外殼，真可說是個大問題啊。

目的地的研究所，好像也在進行同種的研究？

研究的資料或樣本，要是有能作為以後實驗提示的東西就好了。

7月19日

越接近預定日，我就越不安……

Raccoon City的電視新聞或報紙，好像都在報導連日來在郊外發生的離奇殺人事件。

雖然我認為不可能，但會是病毒嗎？如果是的話……

不…現在多想也沒用了。為了要調查能如預期般的進行，還是專心在準備工作上吧。

煞車操作手冊

─關於煞車控制裝置的使用─

要使用煞車控制裝置，必須執行以下三個步驟：

「LEVEL 1. 裝置的啟動」

煞車控制裝置，分別設置在車內的以下地方。

‧第一車輛運轉室

‧第五車輛後部甲板

啟動時，後部甲板的裝置需要使用專用磁卡，此時運轉室和後部甲板兩方面的電源都要輸入。

「LEVEL 2. 後部甲板密碼輸入」

後部甲板的裝置，輸入密碼後即可解除電子鎖。輸入結束後，運轉室才可以輸入密碼。

「LEVEL 3. 運轉室密碼輸入」

運轉室的裝置，輸入密碼後即可解除電子鎖。

結束以上步驟後，就可以使用手動煞車。

Marcus的日記

12月4日

我們終於發現了……這個新的病毒！

我們將這個新發現命名為「始祖」。這真是個令人迫不急待想帶回去開始詳細調查的東西。

3月23日

夥伴Spencer說出「要創立公司」這樣的話。我只要能研究「始祖」的話，怎樣都是沒關係的……能讓我放手去做就行了。

8月19日

Spencer說因為要設立養成所，所以要我擔任那裡的所長。

不知道是事業還是什麼的關係，那傢伙也越來越囉唆了。

但是這反而可以利用。

為了研究這個充滿謎題的病毒，我需要一個特別的場所，一個誰也不會妨礙我的特別場所……。

11月30日

Spencer那傢伙……

今天又對我發了牢騷。

只把「始祖」單純作為創造利益的道具，真是愚蠢至極。

但若是那傢伙的發言權越來越大的話，我要想能繼續研究就難了。不盡快讓「始祖」實用化，確保我 的發言權的話……

9月19日

終於抵達了……。

以「始祖」作為基本來開發新型病毒的階段。依據各種實驗的結果，最後決定與水蛭的DNA進行組合。

這應該會是首次「T」成功的例子，「始祖」品種改良的第一號。

10月23日

不行！

使用土撥鼠的實驗，根本不能寄望有更上一層的進展。

哺乳類，果然不用人類實驗體的話，研究不管到什麼時候都沒有辦法前進到下個階段，只是一直原地踏步而已……

11月15日

所內似乎有部分人員已經察覺我的實驗了……但那一點也不需要在意。

要是妨礙我的話，就請他們來「幫忙實驗」吧！

1月13日

終於完成了，我可愛的水蛭們！

以無趣的生活方式活著的傢伙，根本不能理解這種充實感。這樣一來，終於可以讓Spencer閉嘴了。我將支配所有的一切……

1月31日

在我房裡保護秘密的機關好像有被啟動的跡象。似乎有人為了「T」而侵入的樣子，真是個笨蛋。

大概是Spencer養的狗幹得好事吧。

2月11日

接著之前，我又發現探索前往秘密研究所入口的痕跡了。

那傢伙有這個意思的話，我也必須思考一些對應的處置。

當前，就讓William與Albert去把狗燻出來吧。除了可愛的水蛭外，可以信任的就只有那兩人了。

Spencer……我不會這樣就放棄的。

水蛭的育成紀錄

1978年2月3日

開始對實驗體的四隻水蛭注入「始祖」。

為了生存的寄生與捕食，以及繁殖。我認為擁有不斷反覆進行那些事的本能的水蛭，是最適合當作生物兵器的。水蛭們不久後就好像很痛苦

般的扭動，不久後就沉靜下來了。

之後，有好一陣子都沒有明顯的變化。

1978年2月10日

注入開始後的第七天。

水蛭肥大化到全長變為原本的兩倍，可以看到變態的徵兆。產卵也平安無事的結束了，雖然一時倍增到原本的倍數，但因為異常食慾的關係

，牠們開始互吃。

雖然我緊急調度了餌食，但還是失去了兩隻。

1978年3月7日

我以活的餌食飼育水蛭， 卻反而因為餌食的攻擊失去了一半的水蛭。不過水蛭因此學到了教訓，攻擊模式也由單體進行變化成群體進行。

這次事件也讓互吃不再發生。這以超乎我的想像，真是優秀的進化。

1978年4月22日

水蛭們在捕食之外的時間也停止了個體的行動，開始了隨時統合在某種程度下的集團行動。

對所餵食的餌食，也變 得可以以驚人的效率進行攻擊。

1978年4月30日

似乎讓一名所員察覺了我的實驗。〝餌食〞若換成人類的話會怎樣？水蛭們的反應又會如何呢？

1978年6月3日

今天真是了不起的紀念日。牠們開始進行擬態我的樣子！

是因為認定我是牠們的父親嗎？可愛的孩子們，我不會把你們交給任何人的........。

關於B.O.W.的報告

根據到目前為止的研究，就算將始祖病毒直接注入生物體內，不僅會因急劇的細胞變化而破壞其原本組織，由作為兵器的控制方面來看，也

已明確得知這不是最好的方法。

最好的方法果然是在還是細胞時就進行融合，並有必要讓其成長為一個生物。

我為了顯現成 果而作了不少實驗，這就是其報告。

「蟲」，這個由太古時代就生存到現在的生命體，不知道是否已經進化到了極限，就算注入了始祖病毒，也只能確認其因為莫大的能量而造

成的巨大化與攻擊性提昇。由現狀看來，要將牠們當作B.O.W.加以實用化是非常困難的。

「兩棲類」，在青蛙上注入始祖病毒的結果，是讓其跳躍力與舌頭異常的發達。但是於智慧方面卻完全沒有變化。與其這麼說，不如說是因

為捕食性太過於強烈，只要是會動的東西牠什麼都吃。因此可看見將牠作為B.O.W.的極限。

「哺乳類」

將猴子的細胞與始祖病毒組合後，再將其遺傳子加入猴子的受精卵裡。結果，可看見誕生的個體攻擊性有向上提昇，智能也有某程度上的發

達。（不知道是否因為副作用的關係，其視力會變低，而為了彌補這點聽力會提高。）但是作為兵器還是十分不完全。

果然不以人類為基本的話，就不用期望有更上一層的發展。

關於電池液

電池液，使用於電池的液體，是由硫酸和水混合成的稀硫酸。純度必須要很高。

電池液的比重在一般完全放電的狀態時，20ｏC下有1.280±0.010被使用。

電池液的純度，注意電池用稀硫酸不要被其他不純的東西混入了。
