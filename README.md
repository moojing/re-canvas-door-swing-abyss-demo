# Abyss door transition demo

[Open the demo](https://muji.dev/re-canvas-door-swing-abyss-demo/biohazard1/index.html).

A static copy of Biohazard Abyss with random full-screen door transitions before local HTML navigation. Click a section link to play; use the skip button or Escape to continue immediately.

Integration source and installation instructions: [re-canvas-door-swing/examples/abyss](https://github.com/moojing/re-canvas-door-swing/tree/main/examples/abyss).

The archived website content belongs to its original creators. This repository hosts an integration demonstration; it does not claim ownership of the original site or game assets.

GitHub Pages serves the main branch directly. HTML pages are converted from Big5 to UTF-8 for GitHub Pages, which sends UTF-8 response headers. The local archive retains its original bytes.
