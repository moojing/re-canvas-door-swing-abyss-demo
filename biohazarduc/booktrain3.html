Billy 和 Rebecca 在教堂地下發現一個通道，那裡是巨大蝙蝠的棲息地，下去察看，發現通往 Umbrella 的秘密研究所。

深入內部後，兩人發現，這裡就是怪物誕生的源頭。

Rebecca：我想我們能在這裡找到這些問題的源頭，走吧。

開始的場所要取得的有三角錐裡的手榴彈、轉角處的急救噴霧、燈裡的文件〈女王水蛭〉。

進入操車場後先遇到兩隻僵屍，牠們後方有散彈槍，接著就是排除者的襲擊，然後僵屍→排除者→排除者，由於出現的排除者數量眾多，用

衝鋒槍或散彈槍盡快解決。

Billy：在那裡！小心！

在操車場另一側底部可取得武器（玩家在遊戲開始時所選擇的武器）、綠色藥草（Easy 模式），擊破底部的探照燈，拿取榴彈槍AT（解決僵

屍時是取得的好時機）。

Billy：我們可以利用這個到下層去。

平台下降的過程中，遭遇僵屍群，解決僵屍群後，就是大批水蛭與擬態 Marcus，適時使用手榴彈。

到達下層研究所入口後取得綠色藥草，而在綠色藥草更加後方的燈內有文件〈Biohazard 0 摘要１〉，再往右看，一扇門上方的燈內有散彈槍

。此處的僵屍不管牠們也不會有危險，但是擊倒就能增加敵擊破數。

兩人前去調查電梯，此時「原始暴君」出現阻擋兩人的去路。

Billy：那是什麼鬼東西？！

Rebecca：牠過來了！

戰鬥中會發現一株綠色藥草（Hard 模式無）。原始暴君的弱點相信老玩家都知道，就是外露的心臟。

打倒超級暴君後電梯就會開啟，但是裡面的大群僵屍也會朝玩家攻擊，準備散彈槍應戰吧。

Billy：可惡！這裡也有。

解決完電梯內的僵屍後順利搭乘電梯。

CHECK POINT

到達處理廠後一路都是大量水蛭還有擬態 Marcus，想要在此大量累積敵擊破數的玩家手榴彈和榴彈槍都很實用。電梯正面有手榴彈，走到一

半還有兩隻排除者攪局，通路底部有綠色藥草。

在連絡路遇上設備爆炸事件，請依指示按鍵閃避。

在燒卻室，終於找到水蛭的大本營。

Billy：那是之前看到的相片中的男子。

Rebecca：Marcus？！你不是死了嗎…

Marcus：十年前，Spencer 派人暗殺我，還偷走我的研究。沒想到，發生了不可思議的事，那些水蛭們成功與Ｔ病毒融合，把我帶離死亡的深

　　　   淵。現在，我要 Umbrella 付出代價，整個世界都將陷入仇恨的地獄之中！

燒卻室中有道具散彈槍、綠色藥草、榴彈槍AT。女王水蛭第一型態會釋放出小水蛭，並用觸手攻擊，觸手攻擊可用武器來中斷，當牠很接近

時就用散彈槍或榴彈槍，由於不管攻擊哪個部位傷害值都是一樣的，所以不需特別射擊頭部。

Billy：可惡！起不了作用！

這個場地中，要給予牠一定傷害牠才會移動一個視角，在最後階段，玩家會退到入口附近，此時女王水蛭會伸出許多細小觸手進行攻擊，

再給牠一些傷害，玩家就可以離開燒卻室。

一進入搬入口即可取得綠色藥草，架上的紙箱中有文件〈Biohazard 0 摘要２〉、散彈槍，待會轉身以及搭上運輸梯時還有機會可取得。

（廣播）自毀程序已經啟動，所有人員請立即疏散。

Rebecca：自毀程序？！

Billy：再好也不過了，快，啟動啊。

在搭乘運輸梯時，女王水蛭變異成第二型態，從下方追過來了。

Billy：那傢伙到底是怎樣？！

Rebecca：Billy 小心點！牠追上來了！

此時牠的弱點在口內，基本上用手槍來攻擊即可，但是當牠接近時，要趕緊用散彈槍擊退，當牠因為受到攻擊而暫停移動時，請把握時間填

彈。如果在牠接近時無法確實阻止，就會受到傷害，或發生即死攻擊。

Rebecca：我懂了！朝牠嘴巴攻擊！

Billy：這怪物不知道什麼時候該放棄！

　　　現在我該怎麼做？

Rebecca：牠一定有弱點。我們得找個地方把牠困住。

運輸梯總算到達一樓倉庫，女王水蛭在接觸到陽光時，出乎意料似乎很痛苦。

Billy：牠不喜歡陽光！

運輸梯口右側有綠色藥草（Easy 模式），更右側為武器（玩家在遊戲開始時所選擇的武器），左側有散彈槍。後方平台上有綠色藥草，右側

角落為散彈槍。

女王水蛭在陽光下時，口內受到的攻擊為在暗處時的６倍以上，所以要打倒牠最有效率的方法就是讓牠停留在陽光下，但是當玩家給予的傷

害不夠時，女王水蛭是會步步逼近的，玩家將會隨著牠的逼近而後退，因此給予一定的攻擊，讓牠往後退，除了可以避免受到傷害，也能

讓牠最終退到陽光下接受高傷害的攻擊。

Billy：朝牠的弱點攻擊，看來這樣能讓牠退後！上吧！　讓牠到陽光底下去。

Rebecca：牠停住了，好機會！

Billy：在這裡，怪物。

Rebecca：你為什麼不肯放棄呢？

Billy：這傢伙是什麼鬼東西！　我們最好保持距離。

Rebecca：就差一點了…

Billy：結束吧！

女王水蛭要前進時有兩種模式，一種是步行前進，前進後會距離玩家很近；一種是跳躍前進，玩家需依指示按鍵躲避跳躍時的攻擊。跳躍前

進時就會切換視角，基本上在一個視角內，都是先步行接近→後跳躍接近→切換視角。

擊倒女王水蛭後，已經是黎明時分……

Rebecca：我想是時候說再見了，有人正在等我。

Rebecca 一把奪走 Billy 掛在胸前的大牌……

Rebecca：現在正式宣佈 Billy Coen 少尉已經死亡。

Billy：Rebecca，謝謝妳…

Wesker：這兩個人克服所有難題，成功活著逃離，我想是運氣好吧。
